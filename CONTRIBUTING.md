# Como contribuir

Obrigado por querer ajudar o Sementinha! 🌱

## Regras de ouro (não negociáveis)

1. **Nada de propaganda, chat ou rastreador** (analytics, pixel, SDK de anúncio).
2. **Nada de coletar dados das crianças** além de apelido, bichinho e progresso nos jogos.
3. **Nada que leve a criança para fora da salinha** (links externos, sugestões de vídeo).
4. **Segredos só no servidor.** Nunca use variável `VITE_` para chave secreta. O `.env` nunca vai para o git.

## Sugestão ou problema

Abra uma issue usando um dos modelos. Escreva do jeito que você fala, não precisa ser técnico.

## Código

1. Faça um fork e crie um branch.
2. Garanta que o build passa.
3. Abra o pull request preenchendo o modelo.

Mensagens de commit curtas e em português (ex.: `feat: jogo das cores`).
